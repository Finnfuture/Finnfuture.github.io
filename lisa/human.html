离线缓存（sw.js + cache.js）：模型权重 276MB、离线语音 49MB 与页面资源下载一次就存在本机，第二次打开是 0 下载（断网也能开）。 页面上第一次点击（[CLICK] TO START）之后才开始预下载 —— 免得爬虫 / 路人白跑 345MB 流量。
缓存是「每个地址 + 目录、每台设备、每个浏览器」各一份：手机和电脑不共享； 部署在 GitHub Pages 时改了仓库名 / 部署目录（或本地换了端口 / 用局域网 IP） 就是新的一套，会重新下一次。
iPad / iPhone 的 Safari「7 天没访问会清站点存储」：想长期留着就用分享菜单 「添加到主屏幕」，以后从主屏图标打开。
